# Logos de constructeurs

Dépose ici un fichier par marque, nommé d'après la marque en minuscules :

    bmw.svg · porsche.svg · mclaren.svg · ferrari.svg · audi.svg
    lamborghini.svg · mercedes-amg.svg · chevrolet.svg · toyota.svg

La page les détecte toute seule : si le fichier existe, le logo remplace le
nom écrit sur la carte ; s'il n'existe pas, le nom reste. Rien d'autre à changer.

Ils sont affichés en blanc (`filter: brightness(0) invert(1)`), donc un SVG
monochrome sur fond transparent donne le meilleur résultat.

**D'où ils doivent venir :** d'AZ Motorsport, pas d'une banque d'images. Ce sont
des marques déposées. Un revendeur a le droit de les afficher pour dire ce qui est
compatible avec quoi (usage nominatif) — c'est ce que fait tout le créneau — mais
la page doit alors porter la mention d'usage, comme Fabspeed le fait :

> All manufacturer names, symbols and descriptions are used for identification
> purposes only. AZ Motorsport is not affiliated with, nor endorsed by, these
> manufacturers.
